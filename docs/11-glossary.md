# Backend Engineering Glossary

- **libuv**: Multi-platform C library providing asynchronous I/O and the event loop engine in Node.js.
- **Backpressure**: The resistance or flow-control signal created when data is produced faster than it can be consumed.
- **Cache Stampede**: When multiple clients concurrently miss a cache and overwhelm the primary database.
- **Idempotency Key**: A unique token ensuring that an operation can be retried multiple times without unintended duplicate side effects.
