## 📈 What You'll Know

After completing this module, you can answer:

1. **How do I store dates globally?**
   → Always use UTC as integer timestamp

2. **Why does 0.1 + 0.2 ≠ 0.3 in JavaScript?**
   → Floating-point IEEE 754 representation; use integer cents

3. **How do I support 50+ languages?**
   → Use i18next with namespaces and professional translation management

4. **Why is emoji.length === 2 when I have 1 emoji?**
   → UTF-16 surrogate pairs; use spread operator for correct count

5. **How do I handle DST scheduling safely?**
   → Use UTC + IANA timezone pair + unique IDs for deduplication

6. **Which currencies have 3 decimal places?**
   → BHD, KWD, TND (Intl API handles this automatically)

7. **What's the difference between NFC and NFD?**
   → Composed vs decomposed Unicode; both represent café identically

8. **How do I support Arabic and Hebrew?**
   → RTL languages; use CSS direction: rtl and right-to-left text handling

9. **Why did Google Calendar have infinite loops?**
   → DST transitions create ambiguous times; didn't validate properly

10. **How do I safely truncate strings with emoji?**
    → Use grapheme segmentation, not substring; respect combining characters
