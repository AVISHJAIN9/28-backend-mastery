# ACH Bank Transfers with Plaid Integration\n\n## Overview\n\nThis module demonstrates how to build Plaid-powered ACH (Automated Clearing House) bank transfer functionality. ACH is the backbone of direct deposits, payouts, and B2B payments in the US.\n\n## Key Concepts\n\n### Plaid Flow\n1. **Link Token** - User views Plaid Link UI to connect their bank account\n2. **Public Token** - Plaid returns a token after successful authentication\n3. **Access Token** - Exchange public token for permanent access token\n4. **Account Selection** - Choose which bank account to use for ACH\n\n### ACH Processing\n- **Settlement Time**: 1-2 business days (not real-time)\n- **NACHA Rules**: Standardized ACH formatting and batching\n- **Entry Classes**: PPD, CCD, CTX (different use cases)\n- **Routing Number**: Identifies the receiving bank\n- **Account Number**: Masked for security\n\n## Endpoints\n\n### Account Verification\n```\nPOST /api/accounts/verify\nBody: { userId: string, amounts: [0.01, 0.25] }\nVerifies account ownership via micro-deposit amounts\n```\n\n### Get Account\n```\nGET /api/accounts/:id\nReturns linked account details\n```\n\n### Link Bank Account\n```\nPOST /api/accounts/link\nBody: { userId: string, plaidToken: string, accountType: string }\nLinks a user's bank account via Plaid\n```\n\n### Initiate Transfer\n```\nPOST /api/transfers\nBody: { userId: string, accountId: string, amount: number, type: 'debit'|'credit' }\nInitiates an ACH transfer\n```\n\n### Get Transfer Status\n```\nGET /api/transfers/:id\nReturns transfer status (pending, posted, failed)\n```\n\n### List Transfers\n```\nGET /api/transfers?userId=...\nLists all user's ACH transfers\n```\n\n### Plaid Webhook\n```\nPOST /api/webhooks/plaid\nReceives bank account challenges and link events\n```\n\n## Security\n\n- **PII Masking**: Never log account numbers (log last 4 digits only)\n- **Signature Verification**: Validate Plaid webhook signatures\n- **Rate Limiting**: 100 transfers/hour per user\n- **Encryption**: Store access tokens encrypted\n\n## Real-World Example\n\n**Payout Flow** (Marketplace):\n1. Seller links their bank account via Plaid Link\n2. Platform stores access token securely\n3. When payout is due, platform initiates ACH transfer\n4. Bank processes transfer overnight (1-2 day settlement)\n5. Funds appear in seller's account\n6. Platform receives webhook confirmation\n\n## Files\n\n- `server.js` - Express server setup\n- `routes.js` - ACH endpoints\n- `controller.js` - Business logic\n- `middleware.js` - Validation middleware\n- `schema.js` - Joi validation schemas\n- `App.jsx` - React testing UI\n
