# Setup Instructions for ACH Module\n\n## 1. Install Dependencies\n\n```bash\ncd 09-ach-bank-transfers\nnpm install\n```\n\n## 2. Create Plaid Account\n\n1. Go to https://plaid.com/home/\n2. Click \"Get Started\"\n3. Create account using business email\n4. Use Sandbox environment for development\n5. Copy your credentials:\n   - Client ID\n   - Secret Key\n\n## 3. Set Environment Variables\n\nCreate `.env` file:\n\n```\nHTTP_PORT=6109\nPLAID_CLIENT_ID=your_client_id\nPLAID_SECRET=your_secret_key\nPLAID_ENV=sandbox\nJWT_SECRET=your_jwt_secret\n```\n\n## 4. Running the Server\n\n```bash\nnode server.js\n```\n\nExpect output:\n```\nACH Server running on port 6109\n```\n\n## 5. Testing Endpoints\n\n### Verify Account (Micro-deposits)\n```bash\ncurl -X POST http://localhost:6109/api/accounts/verify \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"userId\": \"user_1\",\n    \"amounts\": [0.01, 0.25]\n  }'\n```\n\n### Link Bank Account\n```bash\n# Get link token from Plaid first\ncurl -X POST https://sandbox.plaid.com/link/token/create \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"client_id\": \"YOUR_CLIENT_ID\",\n    \"secret\": \"YOUR_SECRET\",\n    \"user\": { \"client_user_id\": \"user_1\" },\n    \"client_name\": \"MyApp\",\n    \"products\": [\"auth\"],\n    \"country_codes\": [\"US\"],\n    \"language\": \"en\"\n  }'\n\n# Then in frontend, use the link token to open Plaid Link UI\n```\n\n### Initiate ACH Transfer\n```bash\ncurl -X POST http://localhost:6109/api/transfers \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"userId\": \"user_1\",\n    \"accountId\": \"acc_1\",\n    \"amount\": 1000.00,\n    \"type\": \"credit\",\n    \"description\": \"Monthly payout\"\n  }'\n```\n\n### Check Transfer Status\n```bash\ncurl http://localhost:6109/api/transfers/txn_1\n```\n\n## 6. Plaid Sandbox Testing\n\nUse these test credentials in Plaid Link UI:\n- **Username**: user_good\n- **Password**: pass_good\n\nSelects checking account `011000015` automatically.\n\n## 7. React Testing UI\n\n```bash\n# In another terminal\ncd 09-ach-bank-transfers\nnpx http-server . -p 3009\n```\n\nThen open:\n```\nhttp://localhost:3009/preview.html\n```\n\n## Common Issues\n\n| Issue | Solution |\n|-------|----------|\n| `PLAID_CLIENT_ID not found` | Check .env file exists and has correct credentials |\n| `Port 6109 already in use` | `lsof -i :6109` and kill the process |\n| Plaid Link opens but won't work | Use sandbox credentials (user_good/pass_good) |\n| Transfer shows pending forever | Check Plaid webhook is receiving events |\n\n## Next Steps\n\n1.
