## 🎯 WHAT'S INCLUDED IN EACH BACKEND

### Every server.js (400-500 LOC) Has:

1. **Vulnerable Endpoints**
   - `/api/vulnerable/users/:id` - Leaks sensitive data
   - `/api/vulnerable/documents/:id` - Unauthorized access
   - `/api/vulnerable/invoices/:id` - Data breach

2. **Secure Endpoints**
   - `/api/secure/users/:id` - JWT auth + ownership checks
   - `/api/secure/login` - Token issuance
   - `/api/secure/modify` - Authorization validation

3. **Lab Endpoints**
   - `/api/lab/users` - Test user listing
   - `/api/lab/documents` - Test data discovery
   - `/api/lab/invoices` - Test record access

4. **Core Features**
   - JWT Bearer token authentication
   - Winston logging (file + console)
   - Error handling (no stack traces)
   - CORS configuration
   - Rate limiting
   - Mock database
   - Security headers (Helmet)

## 🚀 HOW TO USE

### Start Any Backend

```bash
cd NN-module-name
npm install
npm start
```

### Test Vulnerability (No Auth)

```bash
curl http://localhost:400N/api/vulnerable/users/1
```

### Authenticate

```bash
curl -X POST http://localhost:400N/api/secure/login \
  -H "Content-Type: application/json" \
  -d '{"email":"alice@example.com","password":"password123"}'
```

### Use Secure Endpoint (With Auth)

```bash
curl http://localhost:400N/api/secure/users/1 \
  -H "Authorization: Bearer TOKEN"
```
