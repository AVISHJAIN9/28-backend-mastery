## 🎯 GET STARTED IN 30 SECONDS

### 1. Navigate to Module 02
```bash
cd 02-bola-idor-object-level-auth
```

### 2. Install & Start
```bash
npm install  # (1 minute, first time only)
npm start    # (10 seconds)
```

### 3. See the Vulnerability
```bash
# In another terminal:
curl http://localhost:4002/api/vulnerable/users/1
```

**Result:** See exposed salary, SSN, bank account (breach!) 😱

### 4. See the Defense
```bash
# Login to get JWT token
curl -X POST http://localhost:4002/api/secure/login \
  -H "Content-Type: application/json" \
  -d '{"email":"alice@example.com","password":"password123"}'

# Use token to access secure endpoint
curl http://localhost:4002/api/secure/users/1 \
  -H "Authorization: Bearer TOKEN_FROM_ABOVE"
```

**Result:** See only safe data (protected!) ✓
