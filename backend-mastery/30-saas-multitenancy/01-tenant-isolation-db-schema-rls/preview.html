🔐 Security Implementation

  • Data Isolation: Alice & Bob (Acme) can only see their company's documents. Charlie (Beta) cannot access them.
  • Database Enforcement: RLS policies in PostgreSQL prevent data leaks even if application code fails.
  • Tenant Extraction: Tenant ID comes from JWT token, validated at database level.
  • RLS Test: Verifies all returned data belongs to current tenant's tenant_id.
  • Cascading Deletion: Deleting a tenant removes all associated data automatically.
