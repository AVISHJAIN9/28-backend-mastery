Dry-Run Preview\n\n### Objective\nTest seed application without making changes\n\n### Request\n```bash\ncurl -X POST http://localhost:4007/api/secure/seeds/run \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"seed_file\": \"seed_v1_0_0\",\n    \"environment\": \"development\",\n    \"dry_run\": true\n  }' | jq .\n```\n\n### Expected Response\n```json\n{\n  \"success\": version\n\n### Step 1: Register Second Seed (v1.1.0)\n```bash\ncurl -X POST http://localhost:4007/api/secure/seeds/register \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"name\": \"seed_v1_1_0\",\n    \"version\": \"1.1.0\",\n    \"environment\": \"development\",\n    \"collections\": {\n      \"tags\": [\n        { \"id\": 1, \"name\": \"javascript\", \"slug\": \"javascript\" },\n        { \"id\": 2, \"name\": \"database\", \"slug\": \"database\" },\n        { \"id\": 3, \"name\": \"backend\", \"slug\": \"backend\" }\n      ]\n    },\n    \"force\": false\n  }' | jq .\n```\n\n### Step 2: Apply v1.1.0\n```bash\ncurl -X POST http://localhost:4007/api/secure/seeds/run \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"seed_file\": \"seed_v1_1_0\",\n Will Detect Issues\n```bash\ncurl http://localhost:4007/api/secure/seeds/validate?env=development | jq .\n```\n\n### Expected Response (Shows Issues)\n```json\n{\n  \"success\": true,\n  \"environment\": \"development\",\n  \"integrity\": {\n    \"users\": {\n      \"count\": 5,\n      \"has_nulls\": true,\n      \"status\": \"invalid\"\n    },\n    \"posts\": {\n      \"count\": 4,\n      \"has_nulls\": false,\n      \"orphaned_records\": 1,\n      \"status\": \"invalid\"\n    }\n  },\n  \"overall_status\": \"invalid\"\n}\n```\n\n### Learning Points\n1.
