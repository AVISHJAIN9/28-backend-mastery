# Setup Guide - Optimistic Locking\n\n## Installation\n\n```bash\ncd 02-optimistic-locking-version-column\nnpm install\nnpm start\n# Backend on http://localhost:4002\n```\n\n## Test Successful Update\n\n```bash\n# Get product (note version)\ncurl http://localhost:4002/api/secure/products/1\n\n# Update with correct version\ncurl -X PATCH http://localhost:4002/api/secure/products/1 \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"name\":\"Updated\",\"price\":1199.99,\"currentVersion\":1}'\n\n# Returns: version incremented to 2\n```\n\n## Test Version Conflict\n\n```bash\n# Try with wrong version\ncurl -X PATCH http://localhost:4002/api/secure/products/1 \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"name\":\"Conflict\",\"currentVersion\":1}'\n\n# Returns: 409 Conflict (version now 2)\n```\n\n## Test Concurrent Simulation\n\n```bash\n# Reset version to 1 (for testing)\ncurl -X POST http://localhost:4002/api/test/products/1/reset-version\n\n# Simulate concurrent update\ncurl -X POST http://localhost:4002/api/test/products/1/concurrent-update \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"name\":\"Test\",\"price\":999.99,\"currentVersion\":0}'\n\n# Gets conflict\n```\n\n---\n\n**Setup Time:** 5 min | **Difficulty:** Beginner\n
