# 11 - Service Mesh Observability (Istio, Linkerd)

## Overview
Observing and troubleshooting microservices running in a service mesh.

## What You'll Learn
- Service mesh concepts (Istio, Linkerd)
- mTLS authentication and monitoring
- Traffic flow visualization
- Circuit breakers and failure analysis
- Rate limiting impact on metrics
- Canary deployment monitoring
- Service-to-service communication tracing
- Golden signals in service mesh
- Detecting cascading failures

## Real-World Use Cases
- Managing 100+ microservices
- Canary releases and traffic splitting
- Service resilience patterns
- Compliance-enforced encryption
- Multi-team microservices platforms
