# 10 - Log Aggregation & Centralization (ELK Stack, Splunk)

## Overview
Collecting, indexing, and searching logs from all services in one place.

## What You'll Learn
- Elasticsearch, Logstash, Kibana (ELK) stack
- Splunk log aggregation
- Log parsing and enrichment
- Full-text search capabilities
- Log retention and archival
- Cost management for log storage
- Creating dashboards from log data
- Setting up alerts on log patterns

## Real-World Use Cases
- Debugging issues across distributed systems
- Compliance and audit trail requirements
- Security incident investigation
- Performance analysis across multiple services
- Root cause analysis
