# 12 - Tracing Backends & Analysis (Jaeger, Grafana Tempo)

## Overview
Storing, querying, and analyzing distributed traces at scale.

## What You'll Learn
- Jaeger architecture and deployment
- Grafana Tempo (cost-effective tracing)
- Trace sampling strategies
- Storage backends (Elasticsearch, Cassandra, BadgerDB)
- Trace analysis patterns
- Finding critical paths in traces
- Trace queries and debugging
- Comparing traces to identify issues
- Trace retention policies
- Correlating traces with metrics and logs

## Real-World Use Cases
- Finding slow database calls across services
- Identifying timeout patterns
- Debugging complex multi-service flows
- Understanding user journey bottlenecks
- Compliance audit trails for requests
