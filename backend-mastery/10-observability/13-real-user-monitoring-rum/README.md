# 13 - Real User Monitoring (RUM)

## Overview
Tracking how real users experience your application.

## What You'll Learn
- Frontend performance metrics
- Core Web Vitals (LCP, FID, CLS)
- JavaScript error tracking
- Network performance from user perspective
- Session replay tools
- Browser behavior tracking
- Geo-distributed user experience
- Mobile vs desktop performance
- Correlation with backend metrics
- Privacy-preserving RUM approaches

## Real-World Use Cases
- E-commerce conversion rate optimization
- Mobile app performance monitoring
- SaaS application responsiveness
- PWA performance tracking
- Understanding user experience degradation
- Identifying geography-specific issues
