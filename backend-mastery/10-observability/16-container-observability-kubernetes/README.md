# 16 - Container & Kubernetes Observability

## Overview
Monitoring containerized applications and Kubernetes orchestration.

## What You'll Learn
- Container resource metrics (CPU, memory, disk)
- Kubernetes cluster health monitoring
- Pod and deployment observability
- Kubelet metrics and node status
- etcd monitoring (cluster state)
- Network policies and CNI monitoring
- Persistent volume monitoring
- Secrets management auditing
- Workload scaling metrics
- Helm release tracking
- Multi-cluster observability

## Real-World Use Cases
- Right-sizing container resources
- Detecting OOM or CPU throttling
- Debugging pod eviction issues
- Capacity planning for Kubernetes
- Multi-cluster federation monitoring
- Security policy compliance verification
- Workload migration planning
