# Learning Checklist - Types vs Interfaces

## Concepts
- [ ] Understand the difference between `type` and `interface`
- [ ] Know when to use `type` (flexibility) vs `interface` (objects)
- [ ] Understand declaration merging with interfaces
- [ ] Know about type unions and type intersections
- [ ] Understand primitive types with `type` keyword
- [ ] Learn about tuple types

## Implementation
- [ ] Write schema definitions using both type and interface
- [ ] Create controller functions with typed parameters
- [ ] Write route handlers with proper types
- [ ] Create typed middleware that extends request object
- [ ] Implement error responses with proper types
- [ ] Use union types for status fields

## Testing & Validation
- [ ] Test GET endpoint with typed responses
- [ ] Test POST endpoint with request validation
- [ ] Test type narrowing in conditionals
- [ ] Verify TypeScript catches type errors
- [ ] Test with invalid data to see type enforcement
- [ ] Use React UI to test all endpoints

## Edge Cases
- [ ] Handle optional properties with `?`
- [ ] Test readonly properties
- [ ] Test nested type definitions
- [ ] Handle null/undefined values properly
- [ ] Test discriminated union patterns
- [ ] Handle type compatibility issues

## Production Readiness
- [ ] Add error logging for type mismatches
- [ ] Implement proper HTTP status codes
- [ ] Add CORS and security headers
- [ ] Validate all inputs before type usage
- [ ] Document your type definitions
- [ ] Create clear error messages
