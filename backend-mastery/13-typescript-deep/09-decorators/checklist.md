# Learning Checklist - Decorators

## Decorator Concepts
- [ ] Understand what decorators are and how they work
- [ ] Know the 4 types: class, method, property, parameter
- [ ] Understand decorator syntax and application
- [ ] Learn about decorator factories with parameters
- [ ] Understand how decorators modify behavior
- [ ] Know the execution order of multiple decorators

## Method Decorators
- [ ] Create a logging decorator
- [ ] Create a timing/profiling decorator
- [ ] Create a caching decorator
- [ ] Create a retry decorator with exponential backoff
- [ ] Create a validation decorator
- [ ] Combine multiple method decorators

## Class Decorators
- [ ] Create a class decorator that adds methods
- [ ] Create a sealed class decorator
- [ ] Create a freezing decorator
- [ ] Create a model/table decorator for ORM patterns
- [ ] Add metadata to classes
- [ ] Build class-level behavior

## Property Decorators
- [ ] Create property validators
- [ ] Create getters/setters via decorator
- [ ] Add constraints to properties
- [ ] Create deprecation decorators
- [ ] Implement computed properties
- [ ] Create reactive property decorators

## Practical Patterns
- [ ] Implement @Authenticated decorator for Express
- [ ] Implement @RateLimit decorator
- [ ] Implement @Validate decorator
- [ ] Implement @Deprecated decorator
- [ ] Create @Memoize caching decorator
- [ ] Create @Debounce/Throttle decorators

## Testing & Validation
- [ ] Test decorator execution order
- [ ] Test multiple decorators on single method
- [ ] Test decorator with parameters
- [ ] Test decorator return values
- [ ] Verify logging output
- [ ] Verify timing measurements

## Production Readiness
- [ ] Enable experimentalDecorators in tsconfig.json
- [ ] Document all custom decorators
- [ ] Create reusable decorator library
- [ ] Handle errors in decorated methods
- [ ] Preserve method metadata
- [ ] Performance test decorated code
