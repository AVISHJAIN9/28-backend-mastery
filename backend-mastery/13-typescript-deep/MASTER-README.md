# TypeScript Deep Dive

**Module Code:** 13-typescript-deep

## What You'll Learn

Complete TypeScript deep dive covering fundamentals through advanced expert-level patterns.

### Core Topics

**Fundamentals (1-4)**
- **01 Types Vs Interfaces** - Core type system comparison
- **02 Generics Api Response** - Generic patterns for APIs
- **03 Zod Runtime Compile Time** - Schema validation
- **04 Utility Types Partial Pick Omit** - Type transformation utilities

**Advanced Patterns (5-8)**
- **05 Discriminated Unions** - Type-safe union patterns
- **06 Declaration Merging Extend Express** - Extending types
- **07 Mapped Template Literal Types** - Computed types
- **08 Conditional Types Infer** - Advanced type inference

**Expert Topics (9-15)**
- **09 Decorators** - Class & method decoration
- **10 Type Guards** - Type narrowing & predicates
- **11 Enums** - All enum patterns
- **12 Recursive Types** - Self-referencing structures
- **13 Function Overloads** - Multiple signatures
- **14 This Types & Method Chaining** - Builder patterns
- **15 Type Operators** - keyof, typeof, indexing


## Learning Objectives

By completing this module, you will:

✅ Master TypeScript's complete type system  
✅ Build production-ready code with types  
✅ Know advanced patterns & best practices  
✅ Apply real-world TypeScript solutions  
✅ Understand type theory & inference  
✅ Create reusable type utilities  

## Getting Started

### 1. Start with Theory
Read `theory.md` in each lesson

### 2. Setup Environment
```bash
cd [lesson-folder]
npm install
cp .env.example .env
```

### 3. Run Server
```bash
npm run dev
```

### 4. Open React UI
Navigate to http://localhost:3000

### 5. Test Endpoints
Use the interactive UI to test all endpoints
