# DPDP Act 2023 – Compliance Checklist

## Consent & Notice
- [ ] Consent notices available in relevant Indian languages
- [ ] Consent is granular, specific, and unambiguous
- [ ] Consent notice version recorded at time of consent
- [ ] Mechanism to withdraw consent is easily accessible
- [ ] Children's data processing has verified parental consent

## Data Principal Rights
- [ ] Access request mechanism implemented (30-day SLA)
- [ ] Correction request mechanism implemented (30-day SLA)
- [ ] Erasure request mechanism implemented (30-day SLA)
- [ ] Grievance redressal mechanism implemented (7-day SLA)
- [ ] Nominee registration mechanism implemented

## Organisational Measures
- [ ] Grievance Officer appointed and contact published
- [ ] If SDF: Data Protection Officer appointed in India
- [ ] If SDF: DPIA process established
- [ ] Breach notification procedure defined (Board + Data Principals)
- [ ] Sub-processor (Data Processor) agreements updated for DPDP compliance

## Cross-Border Transfers
- [ ] Inventory of all cross-border data transfers completed
- [ ] Transfers only to Central Government approved countries
- [ ] Transfer records maintained

## Security
- [ ] Technical and organisational security measures documented
- [ ] Breach detection and response plan in place
- [ ] Annual security review scheduled
