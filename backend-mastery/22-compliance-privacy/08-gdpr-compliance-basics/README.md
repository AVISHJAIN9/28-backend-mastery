# 08 – GDPR Compliance Basics

## Overview
A foundational reference module covering the core pillars of GDPR compliance: lawful bases, data subject rights, DPIAs, breach notification, and the Record of Processing Activities (ROPA).

## Files
| File | Purpose |
|------|---------|
| `lawfulBasis.js` | Lawful basis evaluation helper |
| `dpia.js` | Data Protection Impact Assessment template engine |
| `breachNotification.js` | Breach detection and 72-hour notification workflow |
| `ropa.js` | Record of Processing Activities (ROPA) builder |
| `App.jsx` | GDPR compliance dashboard UI |
| `preview.html` | Standalone HTML preview |
| `checklist.md` | Full GDPR compliance checklist |
| `theory.md` | GDPR overview – articles, principles, rights |
| `setup.md` | Integration guide |
