# GDPR Compliance Basics – Master Checklist

## Principles (Art. 5)
- [ ] Lawful basis documented for every processing activity
- [ ] Privacy notice published (plain language, accessible)
- [ ] Data minimisation reviewed — only necessary fields collected
- [ ] Data accuracy process in place (users can update data)
- [ ] Retention periods defined and enforced
- [ ] Security measures documented (encryption, access control, backups)
- [ ] Accountability evidence maintained (ROPA, DPIAs, training records)

## Consent (Art. 7)
- [ ] No pre-ticked boxes
- [ ] Granular consent (one purpose per request)
- [ ] Consent records stored (who, what, when, version)
- [ ] Easy withdrawal mechanism

## Data Subject Rights (Art. 12–22)
- [ ] Right to be informed — Privacy Notice at collection
- [ ] Right of access — Subject Access Request (SAR) process
- [ ] Right to rectification — data correction mechanism
- [ ] Right to erasure — erasure request workflow
- [ ] Right to restrict processing — flag and pause mechanism
- [ ] Right to data portability — export in machine-readable format (JSON/CSV)
- [ ] Right to object — opt-out from legitimate interests processing
- [ ] All rights responded to within 1 month

## Records of Processing (Art. 30)
- [ ] ROPA created and maintained
- [ ] All processing activities documented
- [ ] ROPA reviewed annually
- [ ] Sub-processors listed in ROPA

## Data Protection by Design (Art. 25)
- [ ] Privacy reviewed at start of every new project
- [ ] Default settings privacy-protective
- [ ] DPIA completed for high-risk activities

## Security (Art. 32)
- [ ] Risk assessment completed
- [ ] Encryption at rest and in transit
- [ ] Access controls and least privilege
- [ ] Vulnerability management programme
- [ ] Staff security training

## Breach Notification (Art. 33–34)
- [ ] Breach response plan documented and tested
- [ ] 72-hour notification procedure ready
- [ ] Data subject notification template prepared
- [ ] Breach register maintained

## International Transfers (Art. 44–49)
- [ ] Inventory of all third-country data transfers
- [ ] Adequacy decision, SCCs, or BCRs in place for each transfer
- [ ] Transfer impact assessments completed where required

## DPO (Art. 37–39)
- [ ] DPO appointment assessed (mandatory for public bodies and large-scale monitoring)
- [ ] DPO contact published in privacy notice
- [ ] DPO involved in all high-risk processing decisions
