# ESLint & Prettier Configuration

## What is this?

This module teaches you how to configure **ESLint** (code quality) and **Prettier** (code formatting) in a Node.js/Express project. These tools automatically detect issues, enforce standards, and auto-fix violations.

## Why does it matter?

Code becomes messy without standards. ESLint & Prettier ensure consistency automatically across your entire team.

## How it works (step by step)

1. Developer writes code
2. ESLint checks against rules
3. Prettier auto-formats
4. CI/CD enforces passing linting check

## Key concepts

- ESLint rules: Off, Warning, Error
- Prettier is opinionated (minimal configuration)
- They can conflict (use eslint-config-prettier)
- Most issues auto-fixable

## Common mistakes

- Disabling too many rules
- Not enforcing in CI/CD
- Different configs per person
