# SOLID Principles - Exercises

## Exercise 1: Design a Notification System
Apply SOLID when building:
- NotificationSender (S: single responsibility)
- Different protocols (O: open/closed)
- Interchangeable implementations (L: Liskov)
- Depend on abstractions (D: dependency inversion)

---

## Exercise 2: Plugin System
Build extensible system:
- Core functionality
- Plugins implement interface
- New plugins without modifying core

---

## Exercise 3: Data Validation
Create validation framework:
- EmailValidator, NameValidator, etc.
- CompositeValidator
- Single responsibility per validator
