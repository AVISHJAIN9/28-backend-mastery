# Observer Pattern - Exercises

## Exercise 1: Stock Price Monitor
Create a stock price observer system:
- Stock class (symbol, price)
- Investor class (subscribes to price changes)
- Alert when price changes by X%

---

## Exercise 2: Social Media Notifications
Build notification system:
- User (posts update)
- Followers (get notifications)
- Different notification types (email, SMS, push)

---

## Exercise 3: Form Validation
Create event-driven form validation:
- Form (emits validation events)
- ErrorDisplay (shows errors)
- SuccessIndicator (shows success)

---

## Exercise 4: Temperature Sensor
Build IoT monitoring:
- Sensor (measures temperature)
- Observers (alarm, logger, display)
