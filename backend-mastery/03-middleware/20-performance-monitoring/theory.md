# Performance Monitoring Middleware

Monitor application performance through request timing and resource usage tracking.

## Metrics Collected
- Request duration (hrtime for precision)
- Memory usage change per request
- HTTP status codes
- Slow request detection (>100ms)

## Performance Analysis
- Identify bottleneck endpoints
- Memory leak detection
- Request latency analysis
- Resource utilization tracking

## Best Practices
- Log slow requests automatically
- Set performance baselines
- Aggregate metrics for analysis
- Alert on anomalies
