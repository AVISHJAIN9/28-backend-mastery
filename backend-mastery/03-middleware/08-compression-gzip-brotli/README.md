# Response Compression Middleware

## What is this?
Compression middleware automatically compresses HTTP response bodies (gzip or brotli) to reduce file size during transmission, speeding up content delivery.

## Why does it matter?
- **Bandwidth Reduction**: Can reduce response size 50-90%
- **Faster Transfers**: Smaller files transfer quicker
- **Mobile-Friendly**: Critical for mobile users with limited bandwidth
- **Cost Savings**: Less data transfer = lower hosting costs
- **Performance**: Faster page loads improve user experience
- **Automatic**: Browser automatically decompresses

## How it works (step by step)
1. Request arrives at server
2. Compression middleware checks Accept-Encoding header
3. Browser supports gzip? Brotli? No compression?
4. Response generated by route handler
5. Middleware compresses response body
6. Content-Encoding header set (gzip or br)
7. Compressed response sent to client
8. Browser receives and decompresses automatically
9. JavaScript sees original uncompressed content

## Key concepts
- **Gzip**: Standard compression, wider support
- **Brotli**: Newer, better compression than gzip
- **Threshold**: Minimum size to compress (small files not worth compressing)
- **Accept-Encoding**: Browser tells server what compression it supports
- **Content-Encoding**: Server tells browser how content is compressed
- **Level**: Compression level 1-11 (higher = more CPU but better compression)

## Common mistakes
- Compressing already-compressed formats (images, videos)
- Using high compression levels on high-traffic servers (CPU intensive)
- Not respecting Accept-Encoding header
- Compressing already-small responses (overhead > savings)
- Not monitoring CPU usage

## Real world usage
```javascript
const compression = require('compression');

// Basic compression (gzip if supported)
app.use(compression());

// With options
app.use(compression({
  threshold: 1024,  // Only compress responses > 1KB
  level: 6,         // Compression level (1-11)
  filter: (req, res) => {
    // Don't compress images, videos, PDFs
    if (req.headers['content-type'].includes('video')) {
      return false;
    }
    return compression.filter(req, res);
  }
}));

// Result: Response includes header
// Content-Encoding: gzip
// Response body 70% smaller
```
