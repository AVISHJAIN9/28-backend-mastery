# OAuth/OIDC Controller

## What is this?

OAuth 2.0 and OpenID Connect patterns for modern authentication.

## Features
- OAuth 2.0 authorization
- OpenID Connect identity
- Social login integration
- Token exchange

## Why does it matter?

OAuth/OIDC enables secure third-party integrations and user authentication.

## How it works

1. User initiates login
2. Redirect to OAuth provider
3. User grants consent
4. Provider redirects with code
5. Exchange code for tokens
6. Verify identity and create session

## Real world usage

- Social logins (Google, GitHub)
- Enterprise SSO
- Multi-tenant applications
- Service-to-service auth
