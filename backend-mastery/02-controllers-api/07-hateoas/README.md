# HATEOAS Controller

Hypermedia As The Engine Of Application State - REST API with discoverable links and actions.

## Key Features

- **Dynamic Links**: Each response includes navigation links (self, next, prev, create)
- **Action Discovery**: Clients learn available operations without hardcoding URLs
- **Pagination Links**: Built-in next/prev links for browsing
- **Self-Describing**: Resources include metadata about available operations
- **Reduced Coupling**: Client logic decoupled from URL structure changes
