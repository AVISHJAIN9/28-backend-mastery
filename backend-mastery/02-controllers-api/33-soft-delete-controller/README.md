# Soft Delete Controller

## What is this?

Logical deletion patterns where records are marked deleted but not removed from database.

## Features
- Mark as deleted with timestamp
- Recover deleted records
- Filter deleted in queries
- Audit trail preservation

## Why does it matter?

Soft deletes preserve data integrity and enable recovery/audit compliance.

## Real world usage

- GDPR right to be forgotten (with retention)
- Undo functionality
- Data recovery windows
- Compliance & audit trails
