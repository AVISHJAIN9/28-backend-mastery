# ABAC - Attribute-Based Access Control

## What is this?
Access control based on attributes (user attributes, resource attributes, environment). Policy engine evaluates attributes to make decisions.

## Why does it matter?
- Extreme flexibility for complex scenarios
- Context-aware authorization
- Handles dynamic scenarios
- Supports any combination of attributes
- Future-proof access control

## How it works
1. Define policies using attributes
2. Evaluate user attributes (dept, level, team)
3. Evaluate resource attributes (classification, owner)
4. Evaluate environment (time, location, IP)
5. Policy engine matches all conditions
6. Allow or deny based on policy

## Key concepts
- **Attributes**: Properties of users, resources, environment
- **Policy**: Rules combining multiple attributes
- **Policy Engine**: Evaluates attribute combinations
- **Context**: Current time, location, IP, device
- **Flexible**: Add new attributes without code changes
