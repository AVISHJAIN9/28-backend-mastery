# Risk-Based Authentication

Adaptive authentication that adjusts security requirements based on contextual risk factors.

## Why it matters

- **Frictionless Security**: Low-risk logins proceed smoothly, high-risk triggers additional checks
- **Threat Prevention**: Detects account takeover attempts and impossible travel
- **Compliance**: GDPR and PSD2 require risk-based Strong Customer Authentication
- **User Experience**: Different security levels for different operations
