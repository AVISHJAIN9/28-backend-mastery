🔐 OAuth2 Google Social Login

Secure authentication using Google accounts

What is OAuth2?

OAuth2 is an open standard for authorization that allows users to sign in using their existing Google account instead of creating a new username/password.

Traditional Login

  • User creates account
  • Stores password
  • Manages password reset
  • Responsible for security

OAuth2 Login

  • User clicks "Sign in with Google"
  • Redirects to Google
  • Google handles password
  • You receive trusted token
Key Benefit: You never store user passwords. Google handles authentication securely.

Key Concepts

1. Authorization Code

Temporary code from Google that your backend exchanges for tokens.

code=4/0AY-t7... (expires in 10 minutes)

2. State Parameter

Random string to prevent CSRF attacks. Ensures callback came from Google.

state=a3f5k9m1p2... (unique, stored server-side)

3. ID Token

JWT containing user info (email, name, picture) signed by Google.

id_token=eyJhbGc... (JWT containing user claims)

4. Access Token

Token to access Google APIs on behalf of user (optional).

access_token=ya29... (can call Google APIs)

Security Features

🔒

No Password Storage

You never receive or store user passwords

🛡️

CSRF Protection

State parameter validates callback origin

✔️

Token Validation

ID token verified with Google's public key

⏱️

Token Expiry

Codes and tokens expire automatically

🔐 Redirect URI Validation: Google verifies redirect_uri matches registered URI. Prevents authorization code from being stolen.

API Endpoints

GET /auth/google/url

Get Google OAuth authorization URL

{ "authUrl": "https://accounts.google.com/o/oauth2/v2/auth?..." }
GET /auth/google/callback?code=...&state=...

Handle Google callback (user redirected here)

{ "user": { "id": "uuid", "email": "user@gmail.com", "name": "John Doe", "picture": "https://..." }, "tokens": { "accessToken": "jwt...", "refreshToken": "jwt..." } }
POST /auth/google/logout

Logout user (invalidate tokens)

How to Test This Module

Step 1: Get Authorization URL

Backend returns Google OAuth URL with proper parameters

Step 2: Click Google Login Button

Frontend redirects to Google login page

Step 3: User Signs In (at Google)

Google handles authentication securely

Note: You don't handle password here. Google does.

Step 4: Backend Receives Code

Google redirects back with authorization code

Redirect: http://localhost:3000/callback?code=4/0AY&state=abc123

Step 5: Exchange Code for Tokens

Backend exchanges code with Google for user info

Step 6: User is Authenticated

Backend returns JWT tokens and user info

Result: User logged in, can access protected routes

Quick Start

  1. Get Google OAuth credentials from Google Cloud Console
    client_id: xxx.apps.googleusercontent.com client_secret: XXXXXX redirect_uri: http://localhost:3000/callback
  2. Set environment variables in .env
    GOOGLE_CLIENT_ID=xxx.apps.googleusercontent.com GOOGLE_CLIENT_SECRET=XXXXXX GOOGLE_REDIRECT_URI=http://localhost:3000/callback
  3. Start the server: node server.js
  4. Click "Sign in with Google" button in frontend
  5. Check user is created in backend and authenticated
