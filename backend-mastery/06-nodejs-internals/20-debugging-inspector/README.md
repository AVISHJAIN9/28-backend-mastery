# 20: Debugging & Inspector

## Overview
Node.js Inspector enables remote debugging with Chrome DevTools. Debug running processes, inspect variables, and profile performance in real-time.

## What You'll Learn
- Starting inspector with --inspect flags
- Chrome DevTools connection
- Breakpoints and step debugging
- Call stack inspection
- Performance profiling

## Key Concepts
- Inspector listens on localhost:9229
- Pause execution at breakpoints
- Variable inspection at any scope
- Remote debugging across networks

## Quick Start
1. `npm install` - Install dependencies
2. `npm start` - Start server
3. Open `http://localhost:3020` - Access UI
