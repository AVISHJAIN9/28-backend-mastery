## Getting Started

### 1. Start with Theory
Read `theory.md` in the first lesson

### 2. Setup Environment
```bash
cd [first-lesson]
npm install
cp .env.example .env
```

### 3. Run Server
```bash
npm run dev
```

### 4. Open React UI
Navigate to http://localhost:3000

### 5. Test Endpoints
Use the interactive UI to test all endpoints
